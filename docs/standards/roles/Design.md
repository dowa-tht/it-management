# Design (UX/UI)

> **Note:** นี่คือ template มาตรฐาน ให้ปรับรายละเอียดตาม project ที่นำไปใช้

---

## Role Overview
Design team รับผิดชอบการออกแบบประสบการณ์และหน้าตาของระบบ ตั้งแต่การเข้าใจพฤติกรรมผู้ใช้ จนถึงการส่งมอบ design ที่พร้อมให้ทีม dev นำไปพัฒนา

---

## Key Responsibilities
- วิเคราะห์ผู้ใช้งาน (User Research) และกำหนด Persona
- ออกแบบ User Flow และ Information Architecture
- สร้าง Wireframe และ Prototype
- ออกแบบ UI ที่สอดคล้องกับ Brand และ Design System
- ทำ Usability Testing และปรับปรุงตาม feedback

---

## Key Deliverables
- User Persona & Journey Map
- Wireframe (Low / High Fidelity)
- Interactive Prototype
- UI Design (Mockup)
- Design System / Component Library
- Handoff Spec สำหรับ Developer

---

## Tools & Standards
- **Design:** Figma, Adobe XD, Sketch
- **Prototyping:** Figma, InVision, Marvel
- **Research:** Maze, Hotjar, Google Forms
- **Handoff:** Zeplin, Figma Dev Mode
- **Standard:** WCAG 2.1 (Accessibility), 8pt Grid System
