# Project Manager (PM)

> **Note:** นี่คือ template มาตรฐาน ให้ปรับรายละเอียดตาม project ที่นำไปใช้

---

## Role Overview
PM รับผิดชอบการบริหารจัดการ project ในภาพรวม ตั้งแต่การวางแผน
ควบคุม timeline, budget, และ resource จนถึงการส่งมอบงานให้ลูกค้า

---

## Key Responsibilities
- วางแผนและกำหนด project scope, timeline และ budget
- บริหาร resource และประสานงานระหว่างทีม
- ติดตามความคืบหน้าและรายงานสถานะ project
- ระบุ บริหาร และลด project risk
- เป็นจุดติดต่อหลักระหว่าง stakeholder และทีมพัฒนา
- จัดการ change request และ scope creep

---

## Key Deliverables
- Project Charter
- Project Plan / WBS (Work Breakdown Structure)
- Risk Register
- Status Report (รายสัปดาห์ / รายเดือน)
- Meeting Minutes
- Change Request Log
- Project Closure Report

---

## Tools & Standards
- **Project Management:** MS Project, Jira, Asana, Monday.com
- **Communication:** Slack, Microsoft Teams, Email
- **Documentation:** Confluence, Notion, SharePoint
- **Methodology:** Agile (Scrum / Kanban), Waterfall, Hybrid
- **Standard:** PMBOK, PRINCE2, PMI

---

## Project Phases
1. **Initiation** — กำหนด objective, stakeholder, feasibility
2. **Planning** — วาง scope, timeline, budget, resource plan
3. **Execution** — ควบคุมการพัฒนา, ประสานงานทีม
4. **Monitoring & Control** — ติดตาม progress, จัดการ risk & change
5. **Closure** — ส่งมอบงาน, สรุปบทเรียน (Lessons Learned)
